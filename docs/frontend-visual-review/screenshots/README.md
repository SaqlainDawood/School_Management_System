# Frontend Visual Review - Screenshots Directory

This directory stores visual verification artifacts and visual regression audit captures for the School Management System Enterprise SaaS UI.

## Structure & Categories
- `desktop/`: Full 1440x900 desktop viewport renders of all 7 role portals (Super Admin, School Admin, Teacher, Student, Parent, Coordinator, Examination) and public routes.
- `dark-mode/`: Contrast and elevation verification captures under Dark Theme tokens.
- `modals/`: Dialog captures including ClassDetailModal, VoucherModal, AddFeeModal, StudentForm, TeacherForm, and ConfirmDialog.
- `mobile/`: 375px mobile responsive drawer and viewport checks.
